## Overview

This repository contains a complete financial econometrics project developed as part of the **Stock Market Analytics Zoomcamp (2026)**.

The project applies econometric techniques, exploratory data analysis, feature engineering, machine learning, and financial simulations to predict stock market movements using historical U.S. equity market data.

The primary objective is to build interpretable predictive models capable of generating profitable trading signals while evaluating investment performance using financial metrics such as CAGR, precision, recall, and trading efficiency.

---

# Project Objectives

- Perform Exploratory Data Analysis (EDA)
- Clean and preprocess financial datasets
- Engineer predictive financial features
- Build Machine Learning classification models
- Evaluate prediction accuracy
- Simulate algorithmic trading strategies
- Measure investment performance using CAGR
- Compare different probability decision thresholds
- Optimize trading efficiency

# Installation

Clone the repository

```bash
git clone https://github.com/rasheey97-alt/Financial-Econometrics-Data-Analysis.git
```

Move into the project

```bash
cd Financial-Econometrics-Data-Analysis
```

Install packages

```bash
pip install pandas numpy matplotlib seaborn scikit-learn yfinance
```

Run

```bash
jupyter notebook
```

or open in Google Colab.
